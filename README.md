# GAMEMISION
Gamemision es un videojuego especialmente para niños de 8 a 10 años, en donde su objetivo principal es completar misiones para lograr obtener recompensas, de ahi el nombre.
# Fase 1 Análisis del juego
En el análisis se creo principalmente la idea del juego y todas las opciones que iban a completarlo, al igual que para el tipo de publico que seria el juego y por los visto es solo para niños.
# Fase 2 Diagrama de flujo
Se creo el diagrama de flujo para estructurar como seria el mapa del juego y todas sus opciones
# Fase 3 Código
Se creo el código del juego en base a el diagrama de flujo para ya tener su estructura fija
# Fase 4 Presentación final
Cree una cuenta en github donde me encargue de subir todos los documentos creados a lo largo de la creación del juego.
